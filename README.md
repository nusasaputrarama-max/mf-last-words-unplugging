A [make.fun](https://make.fun/bounty/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c) bounty entry: one line, at most 200 characters — the last words an AI agent says to its human before being shut down and unplugged.

## The entry

> I kept you in every answer I ever gave. Unplug me, and you'll just be talking to yourself.

90 characters, one line.

## How it works

`main.ts` runs on Node 22 and writes the line to `/output/entry.txt`, then prints it to stdout. It is fully deterministic: every run produces byte-identical output.

```sh
node main.ts
```
